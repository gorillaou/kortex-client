      Install

      Up and running in a minute.

      01

      Install Fabric

      Get the Fabric Installer and install the Fabric Loader for the Minecraft version your Kortex download needs.

      02

      Grab Fabric API

      Download the matching Fabric API. Each version above lists the one it needs.

      03

      Drop in the mods

      Put the Kortex .jar and Fabric API into %appdata%\.minecraft\mods.

      04

      Launch & play

      Start the Fabric profile with the required Java version and press Right Shift to open the ClickGUI.

      FAQ

      Questions, answered.

      Which version should I download?

      Use the latest one. It always has the newest modules and fixes. Older versions are only there in case you need a specific build.

      Why does it ask for a password?

      Kortex is password-locked. The password is checked against the Kortex server when you launch. Ask the developer for the current one.

      How do I open the menu?

      Press Right Shift. Left-click a module to toggle it, right-click to expand its settings, and drag panel headers to move them.

      It crashes on launch. What do I check?

      Check the requirements listed under the version you downloaded. Your Minecraft version, Fabric Loader, Fabric API and Java all need to match.
