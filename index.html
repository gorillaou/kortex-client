How to install

  1. Install Fabric Loader 0.19.5+ for Minecraft 26.3.
  2. Download Fabric API for 26.3.
  3. Put the Kortex .jar and Fabric API into your .minecraft/mods folder.
  4. Launch the Fabric profile (Java 25+ required) and press Right Shift to open the ClickGUI.

Requirements

Minecraft26.3
Fabric Loader0.19.5+
Fabric API0.162.0+26.3
Java25+
